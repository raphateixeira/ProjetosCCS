# TCC — Raissa Stephany Teixeira Paiva

Filtro Sallen-Key como pocket-lab para ensino de identificação e controle de
sistemas dinâmicos: projeto da placa, identificação e projeto de
controladores.

- **Orientador:** Prof. Dr. Raphael Barros Teixeira
- **Trabalho de Conclusão de Curso, 2025:** [Filtro Sallen-Key como pocket-lab para ensino de identificação e controle de sistemas dinâmicos](https://bdm.ufpa.br/items/f010c31b-a220-4e7a-8d31-bee892d965aa)

Dados e códigos do trabalho, trazidos em 2026-10-25 do antigo repositório `FiltroSK` (com o histórico):

- `modelagem-analítica.ipynb` — modelagem analítica do filtro;
- `Identificação_MMQ.ipynb` — identificação por mínimos quadrados a partir de PRBS (`Dados_SK.npy`), com validação;
- `ModeloLSTMdoSK.keras` — modelo LSTM treinado do filtro;
- `SINAL_PRBS.png`, `validação.png` — figuras.

As referências em PDF (notas de aplicação da TI e trabalhos de terceiros) ficam só na máquina local.
